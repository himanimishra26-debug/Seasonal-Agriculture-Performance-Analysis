# Seasonal Agriculture Performance Analysis

## Project Overview
This is a Data Analytics project completed as part of the VOIS & Vodafone Idea Foundation AICTE Internship Program. The project analyzes how agricultural performance varies across different seasons (Kharif, Rabi, and Zaid) using a dataset of ~4000 farm records across various Indian states.

## Problem Statement
Agricultural activities are influenced by seasonal variations in environmental conditions, farming practices, resource availability, and market conditions. This project investigates seasonal differences in agricultural performance by identifying meaningful patterns, trends, relationships, and variations in the available data.

## Dataset
The dataset includes information on farming practices, environmental conditions (rainfall, temperature, humidity, soil quality), resource usage (fertilizer, pesticide, water), and economic outcomes (yield, production, cost, revenue, profit) across seasons.

## Tools & Technologies

- Pandas

## Key Steps
1. Data exploration and understanding
2. Data cleaning (handling missing values, checking duplicates)
3. Exploratory Data Analysis (EDA) across seasons and crops
4. Correlation analysis between environmental, resource, and economic variables
5. Insight generation and data-driven recommendations

## Key Findings
- Kharif is the strongest season overall in terms of yield, profit, and water efficiency, while Zaid consistently underperforms due to higher costs and lower revenue.
- Water efficiency has a strong positive correlation (0.91) with yield, making it one of the biggest drivers of agricultural performance.
- Drip irrigation significantly outperforms other irrigation methods in terms of average profit.
- High-value crops like Sugarcane and Chilli remain profitable across all seasons, while staple crops like Wheat, Rice, and Maize are loss-making across all seasons.
